# Hi, I'm Ammend 👋

I am an R&D engineer with 10+ years of experience in large-scale internet and cloud infrastructure. My work sits at the intersection of **DevOps, software supply-chain security, open source, and AI agents**.

I care about turning emerging technology into dependable engineering systems: reproducible agent tools, portable context, secure execution, and open standards that teams can actually adopt. I also speak and write about what I learn, with the goal of helping more people benefit from open technology.

## What I am building now

My current focus is the infrastructure around AI agents—not only model capability, but also how agents collaborate, preserve context, execute safely, and produce reproducible results.

- **[handoffX](https://github.com/ammend/handoffX)** — an open, portable, Markdown-native context handoff protocol for transferring work across AI agents, sessions, owners, platforms, and infrastructure. It includes an installable Agent Skill, a reference CLI, schemas, and multi-receiver negotiation semantics.
- **[ShellLane](https://github.com/ammend/shelllane)** — an identity-aware shell execution router for local, SSH, and container runtimes. It gives AI coding tools isolated user state and policy-controlled execution without requiring vendor-specific adapters.
- **[botmux](https://github.com/deepcoldy/botmux)** — contributing to the bridge between Feishu/Lark and AI coding CLIs. My recent merged contribution added programmatic management of Lark group tabs across the CLI, OpenAPI layer, commands, documentation, and tests ([PR #1388](https://github.com/deepcoldy/botmux/pull/1388)).
- **[CloudWeGo Eino](https://github.com/cloudwego/eino)** — contributing to the Go framework for LLM/AI applications. My recent merged fix made agent-facing in-memory filesystem queries deterministic, improving reproducibility for prompts, snapshots, and caches ([PR #1297](https://github.com/cloudwego/eino/pull/1297)).
